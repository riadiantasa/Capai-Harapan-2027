Syarat dan Ketentuan Layanan

Terakhir diperbarui: 16 Oktober 2026

1. Penerimaan Syarat

Dengan mengakses dan menggunakan Aplikasi Panduan Capai Harapan Juwara 2027 ("Aplikasi"), Anda menyetujui untuk terikat oleh Syarat dan Ketentuan Layanan ini. Jika Anda tidak menyetujui sebagian atau seluruh ketentuan ini, mohon untuk tidak menggunakan Aplikasi ini.

2. Deskripsi Layanan

Aplikasi ini adalah alat bantu (kalkulator dan jurnal) untuk mencatat transaksi harian, memantau alokasi keuntungan, dan merencanakan target keuangan (STMJ+). Angka simulasi yang dihasilkan oleh Aplikasi ini adalah estimasi dan perencanaan, bukan merupakan jaminan keuntungan nyata warung Anda.

3. Penyimpanan dan Kehilangan Data

Sistem utama Aplikasi ini bekerja secara luring (offline) dengan menyimpan data di dalam memori peramban (browser cache/IndexedDB) perangkat Anda. Oleh karena itu:

  • Kami tidak bertanggung jawab atas hilangnya data jika Anda menghapus riwayat peramban (Clear Data/Cache), mereset pabrik perangkat Anda, atau jika perangkat Anda rusak.
  • Anda sangat disarankan untuk secara rutin melakukan pencadangan data menggunakan fitur Unduh Semua (Excel) atau fitur sinkronisasi Google Drive yang tersedia.

4. Integrasi Pihak Ketiga (Google Drive)

Aplikasi menggunakan layanan Google API untuk memberikan fitur pencadangan. Dengan menggunakan fitur ini, Anda memberikan izin kepada Aplikasi untuk membuat dan mengunggah file laporan berekstensi Excel (.xlsx) ke akun Google Drive pribadi Anda. Kami tunduk pada batasan akses yang diwajibkan oleh Google (Penggunaan Terbatas) dan tidak akan memanipulasi file pribadi Anda yang lain.

5. Penafian (Disclaimer)

Aplikasi disediakan secara "sebagaimana adanya" (as is). Kami tidak memberikan jaminan bahwa Aplikasi akan selalu bebas dari kesalahan (error) atau gangguan. Kami tidak bertanggung jawab atas segala kerugian finansial atau bisnis yang timbul akibat kesalahan input data atau kegagalan sistem pada Aplikasi.
